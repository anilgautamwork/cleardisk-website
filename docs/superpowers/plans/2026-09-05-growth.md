# ClearDisk Growth Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for independent content tasks; controller implements analytics and integration.

**Goal:** Deploy trustworthy download measurement, twelve useful storage articles, crawlable sitemap and an evidence-based marketing plan.
**Architecture:** Existing Vinext SSR Worker gets a custom entry exporting a SQLite Durable Object and intercepting only download/owner-analytics paths. Two typed Guide[] modules extend current guide registry. Public source remains separate from ignored analytics password.
**Tech Stack:** Vinext, React, TypeScript, Cloudflare Workers/Durable Objects, node:test.
**Spec:** docs/superpowers/specs/2026-09-05-growth-design.md

## Global constraints
- Domain cleardisk.app; Stripe test only; Talivia paused. Preserve working native DMG and current website design.
- Aggregate successful full download requests only, not unique users/installs. No IP/raw referrer/cookie storage. 366-day retention.
- Owner dashboard authenticated, noindex/no-store, no public tracking-write endpoint. Fail open for downloads if measurement fails.
- Content must cite verified primary sources. Search volumes are unavailable, not zero or invented.
