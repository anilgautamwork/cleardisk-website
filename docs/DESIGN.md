# ClearDisk website

A standalone website in website/ preserves Claude's native app and planned web/ license worker. Existing production spec is the source of truth: $10 USD once, three personal Macs, all 1.x updates, 30-day refund policy. The app explains System Data with Safe / Review / Leave it labels, scans locally, and trashes before permanent removal.

Visual direction: near-black canvas, oversized tightly set type, lavender accent, a luminous ThreeUI horizon and a precise interactive Mac window. Alternatives considered: a light Apple utility page (less distinctive), and a full 3D cinematic story (heavier and obscures the product). Use the dark product-led direction. No invented testimonials, performance benchmarks, user counts, or scan findings presented as real.

Flow: benefit → free scan / product demo → explain hidden storage → safety → $10 offer → FAQ → close. The product preview uses labeled example data and never accesses local files. Purchase and download are real configurable destinations; absent checkout is disclosed, never simulated as successful. Supporting download, purchase, privacy and terms pages share the brand. Respect reduced motion, keyboard navigation, mobile layouts and WebGL unavailability.

Implementation: complete landing slice, preview, then interactive demo and supporting routes, verify type/build and purchase link behavior, private deployment. Adapt MengTo/threeui EmeraldHorizon shader with attribution, using native WebGL for a small import graph. Match actual app naming and supported macOS 15+ platform.
