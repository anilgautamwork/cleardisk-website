SHORT DESCRIPTION
ClearDisk is a Mac storage app that helps you find large files, understand System Data and review developer clutter. Scans run locally and are free. A one-time license unlocks cleanup, with a review before removal and a Move to Trash option.

REVIEWER NOTES
2.2.1 keeps Disk scan, Why Slow and Permissions visible, explains unavailable storage sections, and preserves scan state when opening permission help. Why Slow opens the process list for CPU and memory review and confirmed quit actions. The horizontal status bar shows disk space, CPU and memory pressure. The optional menu-bar icon adds a memory/CPU-sorted running-app list with confirmed Quit actions. Monitoring runs while the window or menu bar is open; existing local history preferences apply. After a completed scan, its menu shows large files and cache/developer-junk measurements with review links; no direct file deletion. It does not grant macOS permissions automatically.
Performance in 2.2.0 brings the WhySlow tools into ClearDisk: CPU/memory readings, process explanations, background items, internet checks, local usage charts and optional menu-bar monitoring. Supported Chrome/Brave/Edge browser review requires Automation access. Usage history is local and can be disabled or cleared. Confirmed performance actions use the existing license. Monitoring cannot diagnose hardware faults or guarantee a faster Mac.
Scan totals are not guaranteed reclaimable space. Use disposable sample files to demonstrate cleanup. Undo requires the items to remain in Trash; permanent deletion cannot be undone.
Mac checks in 2.1.0 measure readable recognized Apple Intelligence model-asset folders; protected or partial locations are reported. No model deletion or complete-footprint guarantee.
Intel-app checks inspect main executables under /Applications and ~/Applications, including subfolders. Helpers, plug-ins and other locations are outside the scan. Results do not guarantee future macOS compatibility.
iCloud Doctor provides local diagnostics. It does not increase iCloud quota or promise to repair every sync issue.
